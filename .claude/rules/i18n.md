# Internationalization

Loaded when a component or a locale file is read. Each line is the rule; the link is the full text.

- **Every user-facing string goes through `t()` from `react-i18next`** (`const { t } = useTranslation()`), with no display text in JSX, so both languages stay complete. → `docs/lessons/i18n.md` (All User-Facing Strings Use t())
- **Name keys `feature.section.key` in dot notation** (`auth.login.title`, `common.actions.save`). → `docs/lessons/i18n.md` (Translation Key Format)
- **Add every new key to both `en.json` and `es.json`**: a key missing from either is a build-time error. → `docs/lessons/i18n.md` (Supported Locales)
- **Sunfest locales are `apps/sunfest2027/src/locales/`; Links are `apps/links/src/locales/`; Moonfest is `apps/moonfest2026/src/shared/infrastructure/i18n/locales/`.** Section copy lives in the app's own folder, not a shared one. → `docs/lessons/i18n.md` (Locale File Location)
- **Log messages, error codes, console output and test fixtures need no i18n.** → `docs/lessons/i18n.md` (What Does Not Need i18n)
